# Как восстановить пропущенную сводку

Плановые сводки выходят в 09:00, 13:00 и 18:00 МСК. Начните с [журнала сводок #1](https://github.com/Richbanker/team-lead-lab/issues/1) и сопоставьте дату и заголовок последнего отчёта с нужным окном.

## Найдите запуск и проверьте результат

1. Откройте **Actions → [Сводка по задачам](https://github.com/Richbanker/team-lead-lab/actions/workflows/team-pulse.yml)**. Проверьте, что workflow включён. Если он отключён, нажмите **Enable workflow**. Расписание задаётся в [`team-pulse.yml`](../.github/workflows/team-pulse.yml) в `main`.
2. В истории найдите запуск с событием `schedule` около ожидаемого времени по Москве. Если подходящей записи нет, проверьте историю повторно. GitHub может создать запуск позже времени, указанного в расписании. Если сводка нужна сразу, можно получить свежий отчёт вручную.
3. Если запуск ожидает выполнения или ещё идёт, дождитесь результата. Если он завершился ошибкой, откройте задание **report** и раскройте лог шага **Опубликовать сводку**. Если этот шаг пропущен, начните с первого упавшего шага.
4. Если лог сообщает о `team:overview`, проверьте, что [журнал #1](https://github.com/Richbanker/team-lead-lab/issues/1) открыт, создан владельцем репозитория `@Richbanker` и помечен `team:overview`. У владельца должна быть ровно одна открытая задача с этой меткой. Если запрос к API вернул 403, проверьте право `issues: write` в [конфигурации workflow](../.github/workflows/team-pulse.yml) и настройки Actions репозитория.
5. Если запуск успешен, в **Summary** нажмите **Открыть опубликованную сводку**. Сверьте дату и название окна («Утренняя сводка», «Обеденная сводка» или «Вечерняя сводка») в заголовке комментария. URL комментария также есть в логе шага **Опубликовать сводку**.

## Опубликуйте сводку вручную

На странице [«Сводка по задачам»](https://github.com/Richbanker/team-lead-lab/actions/workflows/team-pulse.yml) нажмите **Run workflow**, выберите ветку `main` и подтвердите запуск. В GitHub CLI с правом записи в репозиторий это делается так.

```bash
gh workflow run team-pulse.yml --ref main --repo Richbanker/team-lead-lab
```

1. В истории workflow откройте новый запуск с событием `workflow_dispatch` и дождитесь статуса **Success**.
2. В **Summary** нажмите **Открыть опубликованную сводку**. В [журнале #1](https://github.com/Richbanker/team-lead-lab/issues/1) откроется комментарий от `github-actions[bot]` с заголовком «Сводка по запросу» и актуальным временем по Москве.
3. Если команда запущена повторно в тот же московский день, та же ссылка может вести на обновлённый комментарий. Ручной запуск публикует отдельную сводку по запросу и сохраняет комментарии плановых окон.
