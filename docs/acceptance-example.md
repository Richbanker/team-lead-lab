# Как принять задачу через GitHub

Разберём [задачу #12](https://github.com/Richbanker/team-lead-lab/issues/12), в которой требовалось показать количество блокеров и задач на ревью до длинных списков в сводке.

## До слияния

1. Откройте Issue и сверьте критерии с изменениями. В примере обе цифры должны совпадать с разделами сводки, пустая группа должна показывать ноль, а задача с обеими метками должна учитываться только в блокерах.
2. В [PR #20](https://github.com/Richbanker/team-lead-lab/pull/20) проверьте строку `Closes #12`, описание и вкладку **Files changed**. В этом PR есть тесты пустых и непустых групп и приоритета блокеров.
3. Сверьте проверки с последним коммитом PR. [GitHub Actions](https://github.com/Richbanker/team-lead-lab/actions/runs/45429016548) завершился успешно для `8942d87`. В описании PR также зафиксирован результат предварительного просмотра сводки.
4. Зафиксируйте решение с основанием. Если есть замечание, укажите критерий, наблюдаемый результат и ожидаемое исправление. [В истории PR #20](https://github.com/Richbanker/team-lead-lab/pull/20) видно слияние от `@Richbanker` 24 ноября 2026 года в 19:51 МСК. Отдельного публичного ревью и комментария о приёмке нет.

Пример записи для будущего PR:

> Принято. Счётчики совпадают с разделами, пустые группы показывают ноль, а задача с двумя метками попадает только в блокеры. Проверки на последнем коммите прошли.

## После слияния

1. Убедитесь, что PR имеет состояние **Merged**, а [Issue #12](https://github.com/Richbanker/team-lead-lab/issues/12) помечен **Closed as completed**. Чтобы проверить причину через API, запросите Issue и посмотрите поля `state`, `state_reason` и `closed_at`.

   ```powershell
   Invoke-RestMethod 'https://api.github.com/repos/Richbanker/team-lead-lab/issues/12' |
     Select-Object state, state_reason, closed_at
   ```

2. Проверьте раздел **Принято за 24 часа** в [журнале сводок](https://github.com/Richbanker/team-lead-lab/issues/1). Задача #12 есть в [сводке от 24 ноября в 19:55 МСК](https://github.com/Richbanker/team-lead-lab/issues/1#issuecomment-7138426947). После истечения 24 часов со времени закрытия ищите её в этой публикации или в истории Issue.
